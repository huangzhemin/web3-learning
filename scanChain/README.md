# 区块链扫链演示项目

这是一个完整的区块链扫链演示项目，可以实时监控以太坊区块链上的活动，包括新区块、交易、智能合约调用等。

## 🚀 功能特性

### 核心功能
- **实时区块监控**: 实时接收和显示新区块信息
- **交易跟踪**: 监控所有交易活动，包括转账和合约调用
- **地址扫描**: 扫描特定地址的余额和交易历史
- **安全分析**: 识别可疑交易模式和异常活动
- **Web 界面**: 现代化的用户界面，实时显示数据

### 高级功能
- **智能合约监控**: 检测和分析智能合约交互
- **大额转账警报**: 自动识别大额资金转移
- **风险评估**: 基于多种因素评估交易风险等级
- **实时通知**: WebSocket 实时推送数据更新

## 🛠️ 技术架构

### 后端技术
- **Node.js**: 服务器运行环境
- **Express**: Web 框架
- **Socket.IO**: 实时双向通信
- **Web3.js**: 以太坊区块链交互
- **EventEmitter**: 事件驱动架构

### 前端技术
- **HTML5**: 语义化标记
- **CSS3**: 现代化样式和动画
- **Bootstrap 5**: 响应式 UI 框架
- **JavaScript ES6+**: 现代 JavaScript 特性
- **Socket.IO Client**: 实时数据接收

## 📦 安装说明

### 环境要求
- Node.js 16.0 或更高版本
- npm 或 yarn 包管理器
- 以太坊网络访问权限（Infura、Alchemy 等）

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd scanChain
```

2. **安装依赖**
```bash
npm install
```

3. **配置环境变量**
```bash
cp env.example .env
```

编辑 `.env` 文件，配置以下参数：
```env
# 以太坊网络配置
ETHEREUM_RPC_URL=https://mainnet.infura.io/v3/YOUR_INFURA_PROJECT_ID
ETHEREUM_WS_URL=wss://mainnet.infura.io/ws/v3/YOUR_INFURA_PROJECT_ID

# 扫描配置
SCAN_INTERVAL=1000
MAX_BLOCKS_TO_SCAN=100

# 服务器配置
PORT=3000
NODE_ENV=development
```

4. **启动应用**
```bash
# 开发模式（自动重启）
npm run dev

# 生产模式
npm start
```

5. **访问应用**
打开浏览器访问 `http://localhost:3000`

## 🔧 配置说明

### 网络配置
- **主网**: 连接到以太坊主网
- **测试网**: 连接到 Goerli、Sepolia 等测试网
- **本地网络**: 连接到本地 Hardhat 或 Ganache 节点

### 扫描配置
- **扫描间隔**: 控制扫描频率（毫秒）
- **最大区块数**: 限制扫描的区块数量
- **缓存大小**: 控制内存中缓存的数据量

## 📱 使用指南

### 基本操作

1. **启动实时扫描**
   - 点击"开始实时扫描"按钮
   - 系统将开始监控新区块和交易

2. **扫描特定地址**
   - 在地址输入框中输入以太坊地址
   - 点击"扫描"按钮查看地址信息

3. **查看实时数据**
   - 实时区块流显示最新区块信息
   - 实时交易流显示最新交易
   - 安全警报显示异常活动

### 高级功能

1. **智能合约监控**
   - 自动检测合约调用
   - 分析调用方法和参数

2. **风险评估**
   - 基于多种因素评估交易风险
   - 识别可疑模式和异常活动

3. **数据导出**
   - 支持导出扫描数据
   - 生成分析报告

## 🔍 API 接口

### REST API

- `GET /api/status` - 获取服务器状态
- `GET /api/block/:blockNumber` - 获取区块信息
- `GET /api/address/:address` - 获取地址信息
- `GET /api/transactions` - 获取最近交易

### WebSocket 事件

- `startScanning` - 开始扫描
- `stopScanning` - 停止扫描
- `scanAddress` - 扫描地址
- `scanBlock` - 扫描区块

### 接收事件

- `newBlock` - 新区块通知
- `newTransaction` - 新交易通知
- `contractInteraction` - 合约交互通知
- `largeTransfer` - 大额转账通知

## 🚨 安全注意事项

### 网络安全
- 使用 HTTPS 在生产环境中部署
- 配置适当的 CORS 策略
- 限制 API 访问频率

### 数据安全
- 不要在生产环境中暴露敏感信息
- 定期清理缓存和日志数据
- 监控异常访问模式

### 区块链安全
- 验证所有地址和交易哈希
- 注意钓鱼和诈骗地址
- 定期更新黑名单和白名单
